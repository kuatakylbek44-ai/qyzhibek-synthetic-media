# QYZHIBEK — Синтетикалық медиа және генеративті ЖИ

Қазақ тіліндегі интерактивті оқу сайты. 11-аптаға арналған.

**Орындаған:** Абдилла Қызжібек. Мамандығы: информатика пәнінің мұғалімі.

## Мазмұны

- 7 бөлімнен тұратын толық дәріс және оқылған бөлімдерді белгілеу.
- Браузердегі TTS: дауысты және жылдамдықты таңдау.
- Анимациялық цифрлық аватар, кезеңдік түсіндірме.
- Deepfake иллюстрациясы, мүмкіндік пен қауіптерді салыстыру.
- Ақпаратты тексеру алгоритмі және интерактивті кейс.
- 4 практикалық жұмыс, жауаптарды браузерде сақтау және TXT файлына жүктеу.
- Түсіндірмесі бар 5 сұрақтық тест.

## Іске қосу

Құрастыру және серверлік кілт қажет емес. `index.html` файлын ашуға немесе осы каталогты кез келген статикалық хостингке орналастыруға болады. GitHub Pages: main тармағы, / (root).

Жергілікті HTTP қарау: `python -m http.server 4173`.

## Мүмкіндіктер мен шектеулер

TTS Web Speech API арқылы құрылғыдағы дауыс қызметін қолданады. Қазақша дауыс барлық жүйеде бола бермейді; сайт қолжетімді тілді көрсетеді. Кей дауыс қызметтері интернетті қолдануы мүмкін. Сайтта арнайы дауыс сервері, дауыс клондау немесе deepfake анықтау моделі жоқ. Аватар мен салыстыру — таңбаланған оқу иллюстрациялары.

Студент жауаптары серверге жіберілмейді: тек осы браузердің localStorage қоймасында сақталады. Жұмысты TXT файлына экспорттауға болады. Жеке немесе құпия деректерді жазудың қажеті жоқ.

Дизайн телефон, планшет және компьютерге бейімделген; пернетақтамен басқару және reduced-motion параметрі ескерілген. Manrope қарпі Google Fonts арқылы жүктеледі, желі жоқ болса жүйелік қаріп қолданылады.

Материалдар бастапқы дереккөздерге сілтемелермен берілген: UNESCO, MDN, C2PA. Жобаға API кілттері мен тіркелгі деректері кірмейді.
