## Жариялау

GitHub Pages: main тармағы, / (root). Құрастыру қадамы серверде қажет емес.
Стильдер, Inter қаріптері және Font Awesome 6.5.1 белгішелері assets/ ішінде сақталған.

Жергілікті қарау: `python -m http.server 4173`.
Tailwind сыныптары өзгергенде CSS қайта құрастыру:

```
npx --yes tailwindcss@3.4.17 -c tailwind.config.cjs -i assets/input.css -o assets/tailwind.css --minify
```

## Техникалық ескертпелер

TTS браузердің Web Speech API мүмкіндігін қолданады. Қазақша дауыс болмаса, таңдалған дауыс тілі көрсетіледі. Дауыс қызметі істемесе, дыбыс ойнатылғандай көрсетілмейді. Кейбір құрылғы дауыстары интернетті қажет етуі мүмкін.

Аватар — дайын жауаптары бар оқу симуляциясы. Чек-лист медианың шынайылығын автоматты түрде анықтамайды. Практикум есебінде тек өрістердің толықтығы тексеріледі, мазмұнға автоматты баға қойылмайды. Студент енгізген деректер сайт серверіне жіберілмейді және бетті жапқанда сақталмайды; есепті көшіріп алу керек.

Жариялауға бейімдеу кезінде мобильді рубрика терезесінің айналдыруы, пернетақтамен жабу, жауапсыз кейсті өткізбеу және дыбыстау қатесінің хабарламалары түзетілді. Қызжібектің байланыстары қосылды.
